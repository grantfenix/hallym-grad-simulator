🥇 Cursor

Самый популярный конкурент сейчас.

Основан на VS Code.
Выглядит почти так же.
Встроенный ИИ намного сильнее обычного VS Code.
Может сам искать файлы, писать код и исправлять ошибки по всему проекту.

Для AI-разработки многие уже используют Cursor вместо VS Code.

🥈 Windsurf

Ещё один AI-редактор.

Похож на VS Code.
Сильный агентный ИИ.
Может выполнять цепочки задач по проекту.

Подходит, если хочется больше автоматизации.

🥉 JetBrains IDE

Например:

PyCharm (Python)
WebStorm (JavaScript)
IntelliJ IDEA (Java)

Плюсы:

Очень умные подсказки.
Хороший рефакторинг.
Профессиональные инструменты.

Минус:

Тяжелее VS Code.
Многие функции платные.
☁️ Replit

Вообще не нужно ничего устанавливать.

Код пишется в браузере.
Есть ИИ.
Можно сразу публиковать приложения.

Подходит для учёбы и небольших проектов.

Новый сверхбыстрый редактор.
