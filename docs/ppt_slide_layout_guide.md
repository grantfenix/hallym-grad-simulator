- **슬라이드 목적**: 기존 포털 시스템의 한계와 학생들이 겪는 실제 불편을 증명.

  - 2. 사후 확인의 한계: 학기가 다 끝나고 성적이 확정된 후에야 요건 미달을 인지함.
  - 3. 까다로운 예외: 학번별 교양 기준, 재이수 학점 상한, 특수 학생 기준의 복잡성.

### [Slide 10] 시스템 아키텍처 및 사용 기술 (No AI Slop)
- **슬라이드 목적**: 안정적이고 투명한 기술 스택과 AI/규칙의 명확한 분업 원칙 증명.
- **텍스트 줄 수**: 3개 기술 블록 (각 2줄).
  - 1. 순수 웹 기술 스택: 무거운 프레임워크 종속성 없는 HTML5, Modern CSS3, 순수 ES6+.
  - 2. 데이터 보호: 브라우저 안전 저장소(`localStorage`), 저장용량 자동 보호 및 일방향 암호화.
  - 3. 투명한 역할 분업: AI는 비정형 성적표 OCR을, 규칙 코드는 100% 일관된 학점 계산을 전담.
- **핵심 강조 문구**:
  > **"AI는 비정형 문서 인식을, 규칙 코드는 일관되고 정확한 학점 집계를 분담"**
