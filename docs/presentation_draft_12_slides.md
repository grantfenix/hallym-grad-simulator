## [Slide 2] 프로젝트 개요 (Executive Summary)
- **한 줄 정의**: 복잡한 대학 졸업 요건(130학점, 전공, 공통 교양 6대 영역, 필수 교과목)을 수강 바구니 담기와 동시에 실시간으로 사전 시뮬레이션하는 스마트 웹 플랫폼.
- **기획 배경**:
  - 대학생들은 매 학기 수강 신청 시 주로 '시간표 공강' 맞추기에 집중함.
  - 졸업 마지막 학기에 이르러서야 필수 과목 누락이나 교양 영역 미충족을 발견하여 졸업 유예(초과학기)를 겪는 문제가 빈번함.
- **핵심 비전**: **"실수 없는 수강 계획, 안심하는 대학 졸업"**
- **목표 지표**:
  - 브라우저 기반 무설치 실행 (GitHub Pages 웹 호스팅)
  - 한림대 1,098개 실제 개설 교과목 데이터베이스 탑재
  - 규칙 기반 코드(일관된 결과 제공)와 AI OCR(성적표 편의성)의 투명한 분업

## [Slide 3] 문제 정의 (Problem Definition & User Pain Points)
- **Pain Point 1: 분절된 학적 정보**
  - 수강신청 시스템, 종합정보시스템(포털), 학과 요람 PDF가 각각 흩어져 있어 학생이 일일이 대조해야 함.
- **Pain Point 2: 사후 통보식 확인의 한계**
  - 기존 포털의 졸업 판정은 학기가 끝나고 성적이 확정된 '과거 데이터'만 보여줌.
  - "이번 학기에 이 과목들을 들으면 졸업이 가능한가?"라는 '미래 예측'이 불가능.
- **Pain Point 3: 복잡하고 까다로운 예외 규정**
  - 입학연도(학번)별로 다른 교양 이수 기준 (예: 23학번 이후 글로벌소통 9학점 vs 22학번 이전 6학점).
  - 동일과목 재이수 시 성적 상한(A0) 및 학점 중복 미인정 규칙 미인지로 인한 학점 차질 발생.
- **Pain Point 4: 모바일 접근성 부재**
  - 기존 학사 포털은 모바일 화면에서 표가 깨지거나 폰트가 흐릿하여 이동 중 조회가 극히 불편함.

## [Slide 4] 해결 방안 (Proposed Solution & Value Proposition)
- **핵심 솔루션**: **"수강 바구니 기반 미래 졸업 시뮬레이션"**
- **핵심 차별점 3가지**:
  1. **사전 시뮬레이션 (Predictive Simulation)**:
     - 다음 학기 들을 과목을 장바구니에 담는 즉시 130학점 달성도, 잔여 학점, 영역별 변화를 실시간 게이지로 표출.
  2. **AI 슬롭 방지 & 투명한 분업 (No AI Slop)**:
     - 비정형 성적표 PDF 분석은 **AI OCR**이 담당하여 수동 입력의 번거로움을 해결.
     - 졸업 판정 및 학점 집계는 환각(오류) 없는 **규칙 기반 코드**가 담당하여 일관된 결과를 제공.
  3. **모바일 퍼스트 캠퍼스 UX (Mobile First)**:
     - 스크롤을 내려도 상단에 고정되는 56px 초슬림 Sticky Header.
     - 언제든 내 현황으로 복귀하는 하단 미니 플로팅 바.
     - 터치 편의성을 보장하는 44px 터치 타겟(Apple HIG 준수).

## [Slide 5] 핵심 기능 ①: 맞춤 이수 관리 & 1,098개 과목 DB
- **핵심 학적 유형 지원 (Multi-User Isolation)**:
  - 신입학 재학생뿐 아니라 편입생, 외국인 유학생, 복수전공 이수자 등 핵심 학적 유형별 맞춤 요건 지원.
  - 브라우저 안전 저장소(`localStorage`) 기반 사용자별 격리 저장 (용량 초과 및 데이터 손상 시 자동 복구 가드레일 탑재).
- **1,098개 한림대 전체 개설 과목 내장**:
  - 교과목코드, 교과목명, 학점, 이수구분, 개설학과, 개설학기 데이터 구축.
  - 한글 자모 및 오타 허용 자동완성 검색 기능.
  - 검색 결과에서 즉시 바구니에 담는 `[+ 바로 담기]` 원클릭 인터랙션.
- **성적증명서 원클릭 자동 등록 (AI 파싱 & 예시 데이터)**:
  - 성적증명서 PDF 업로드 시 텍스트 레이어를 광학 인식하여 기이수 테이블에 일괄 등록.
  - 발표 및 평가를 위한 `[📋 예시 성적표 불러오기]` 원클릭 버튼 제공.

## [Slide 6] 핵심 기능 ②: 실시간 시뮬레이션 & 인터랙티브 UX
- **실시간 미래 학점 게이지**:
  - 주전공, 공통 교양, 일반선택 3대 카테고리별 학점 변화 실시간 시각화.
  - 수강 바구니 담기/제거 시 `기이수 + 수강 중 + 장바구니 = 졸업 예상 학점` 실시간 연산.
- **하단 미니 플로팅 장바구니 바 (Floating Basket Bar)**:
  - 모바일이나 PC에서 화면을 길게 스크롤해도 하단에 `[🛒 장바구니: N개 (N학점) ➔ 내 현황 바로가기]` 미니 바 상시 유지.
- **안전 지능형 경고 시스템**:
  - **재이수 감지**: 이미 들었던 과목을 다시 담으면 즉시 "재이수 과목 (신규 학점 미반영, 최대 A0)" 배지 및 경고 팝업.
  - **수강 한도 감지**: 정규학기 수강 가능 한도(18학점)를 초과하여 바구니에 담을 경우 실시간 경고 표시.

## [Slide 10] 시스템 아키텍처 및 사용 기술 (No AI Slop)
- **프론트엔드 (초경량 무설치 웹)**:
  - **HTML5 / Modern CSS3**: CSS Grid, Flexbox, 56px Sticky Header, 44px 터치 타겟 규격 준수.
  - **Vanilla JavaScript (ES6+)**: 별도의 무거운 외부 프레임워크 종속성 없이 순수 자바스크립트로 브라우저에서 즉시 실행.
- **데이터 저장 & 보안 레이어**:
  - **브라우저 안전 저장소**: 사용자 기기 내 로컬 저장소를 활용하고, 저장용량 초과 및 데이터 오류 시 자동 보호/복구.
  - **일방향 암호화**: 비밀번호 및 관리자 인증을 클라이언트 단에서 일방향 해시로 안전하게 검증.
- **AI 연동 & 역할 분업 구조 (No AI Slop)**:
  - **AI OCR 엔진**: 비정형 성적표 PDF 문서에서 과목명과 학점을 광학 인식 (수동 입력 편의성 제공).
  - **규칙 기반 코드 (Rule Engine)**: 학점 집계, 중복 과목 필터링, 졸업 요건 판정 (오류 없는 일관된 결과 제공).
